# BeeMind — Final R1–R4 Design System

- Surfaces: Soft Porcelain `#F2F3F5` for editorial work; dark atmospheric home framing,
  pearl/slate translucent home glass and protected dark ink. Control purple `#654A83`.
- Type: the existing OFL merged Manrope/Tajawal family; Arabic-first, mixed-direction
  content; 19sp/33sp writing/reading, 16sp/27sp bounded home previews.
- Icons: compact, consistent line glyphs with Arabic descriptions in 48dp hit targets;
  the launcher icon is unchanged. Small polished mineral discs carry editor tools.
- Cards: 14dp corners, stable FNV-1a 140/185/234dp masonry, 3/5/7-line previews,
  responsive columns and immutable identity/order. Shared window-aligned diffusion
  reveals photography through translucent material; fine rims/specular light add depth.
- Wallpapers: private unchanged originals, durable pin/current/order, session rotation,
  0–100 gentle blur with a true zero, bounded EXIF-aware processing and cached preview.
  Legacy blur preferences migrate once without deleting images.
- Expression: exclusive Normal/Glow/Anger. Glow is luminous multidirectional iridescence;
  Anger is directional crimson glass. Static bounded aura on home; shared luminous
  porcelain atmosphere in writing/reading. Capsule covers accept only opening time.
- Editing: titleless body, original persistent TextFieldState and serialized autosave,
  durable recovery and safe departure. Bottom-left progressive glass tools retain R3's
  four categories, independent appointment proposals and explicit capsule seal confirmation.
- Reading: open editorial body, lazy safe chunks, selection/copy, fixed compact actions;
  Delete stays behind More with confirmation and success-dependent departure.
- Threads: safe compact related cards naturally follow the article. Centered management
  separates open/remove from the searchable picker. Existing bilateral Room links and
  live updates remain; closed capsule title/body are excluded from preview/search/semantics.
- Interaction: short platform-scaled transitions, precise selection/pressed states,
  no continuous pulsing. IME/insets, RTL, large fonts and narrow layouts remain supported.
- Functional boundary: offline API 26+, Room v6, immutable createdAt/application ID,
  reminders/Done/real Snooze, Resurface, capsule locks, autosave/recovery and signing
  policy remain. No accounts/cloud, launcher change, PR merge or Stage 6 work.

Verification evidence and actual limitations are maintained in REDESIGN_R4.md and
its matching Draft PR, separately from the owner's physical-phone acceptance.
